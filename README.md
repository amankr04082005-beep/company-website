# STCS Company Website

Responsive multi-page static website inspired by the STCS India reference site.

## Files

- `index.html` — company homepage
- `about.html` — company profile and history
- `services.html` — service catalogue
- `projects.html` — project portfolio
- `insights.html` — insights and blog topics
- `careers.html` — career information
- `contact.html` — contact details and inquiry form
- `styles.css` — base responsive styles and animations
- `brand.css` — STCS-branded visual theme
- `pages.css` — shared layouts for separate pages
- `site-shell.js` — shared navigation and footer
- `script.js` — mobile navigation, scroll progress, reveals, carousel, and contact form

## Run locally

Open `index.html` in a browser, or start a local preview server from this folder with:

```powershell
npx --yes http-server . -p 4173 -a 127.0.0.1
```

Then visit `http://127.0.0.1:4173`.

The page uses the official STCS and Y-Fibre image assets, Google Fonts, and Unsplash imagery, so an internet connection is required for those remote assets.
